\# ArsenalTalks Product Principles



\## Vision



ArsenalTalks exists to deliver the smartest Arsenal match experience on the web through premium football journalism, visual analytics, and editorial-quality match intelligence.



Technology powers the experience, but ArsenalTalks is always the brand users interact with.



\---



\# Core Principles



\## 1. Editorial First



Every page should feel like it was produced by a professional football newsroom.



The experience should be comparable to premium football platforms such as:



\* Sky Sports

\* BBC Sport

\* ESPN

\* The Athletic

\* Opta



\---



\## 2. Technology Is Invisible



Users should never see implementation details.



Do not display words such as:



\* AI

\* Artificial Intelligence

\* GPT

\* ChatGPT

\* OpenAI

\* LLM

\* Machine Learning



Internally these technologies may exist, but they must never become part of the public-facing experience.



\---



\## 3. ArsenalTalks Owns The Analysis



Every insight belongs to ArsenalTalks.



Examples:



\* ArsenalTalks Match Verdict

\* ArsenalTalks Match Intelligence

\* ArsenalTalks Tactical Analysis

\* ArsenalTalks Performance Ratings

\* ArsenalTalks Match Centre



\---



\## 4. Football Before Technology



Every feature must answer a football question.



Examples:



What happened?



Why did it happen?



Who influenced the match?



How did tactics change?



Where was the game won?



Technology should help answer these questions rather than become the focus.



\---



\## 5. Premium Design



The interface should feel calm, modern, and professional.



Priorities:



\* Clean layouts

\* Excellent typography

\* Strong visual hierarchy

\* Generous spacing

\* Smooth animations

\* Mobile-first responsiveness



Avoid visual clutter.



\---



\## 6. Storytelling



The Match Centre should guide users through the match in a logical sequence.



1\. Match Overview

2\. Match Verdict

3\. Momentum

4\. Match Intelligence

5\. Tactical Analysis

6\. Player Rankings

7\. Player Awards

8\. Editorial Analysis

9\. Related Reading



Every section should contribute to the story of the match.



\---



\## 7. Brand Language



Use ArsenalTalks terminology consistently.



Examples include:



\* Match Verdict

\* Match Intelligence

\* Tactical Analysis

\* Performance Rating

\* Match Rating

\* Player Spotlight

\* Match Outlook



Avoid generic technical terminology.



\---



\## 8. Data With Context



Statistics alone are never enough.



Every important statistic should be supported by context explaining why it mattered.



The goal is understanding rather than information overload.



\---



\## 9. Consistency



Every page should feel like part of one product.



Colours, spacing, typography, icons, interactions, and terminology should remain consistent throughout the site.



\---



\## 10. Long-Term Goal



The ambition is for ArsenalTalks to become recognised as a trusted destination for Arsenal analysis.



Users should return because they value ArsenalTalks' football insight, presentation, and editorial quality—not because of the technology used behind the scenes.
